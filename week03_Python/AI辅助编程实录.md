# W3 AI 辅助编程实录

任务：用 Python 读取 `data/生词表.csv`，按 HSK 等级筛选并生成造句练习。

## 工具

- Cursor（AI 编程助手）
- 课程骨架：`week03_Python/vocab_tool.py`

## AI 初版思路

向 AI 说明需求后，初版给出的核心步骤是：

1. `csv.DictReader` 读表
2. 列表推导按 `HSK等级` 筛选
3. 写文件生成“用××造句”

初版问题：路径写死为相对路径，换目录运行就找不到 CSV；也没有词性统计。

## 我的修改

1. 改用 `weekpath.data_path("生词表.csv")` 与 `weekpath.root_path("练习.txt")`，任意目录运行都能定位文件。
2. 保留并确认 `encoding="utf-8"`，避免 Windows 中文乱码。
3. 增加 `count_by_pos()`，打印 HSK4 词性分布，方便备课摸底。
4. 逐行读懂：`filter_by_level`、`gen_exercises` 的循环与字符串格式化，能现场讲清。

## 运行结果

```
总词汇 13 个，其中 HSK4 词汇 4 个，词性分布：{'名词': 1, '动词': 3}
已生成：练习.txt
```

`练习.txt` 内容为 4 道造句题（把字句、商量、感动、坚持）。

## 反思

AI 能快速搭出骨架，但路径与编码这类“换机器就坏”的细节必须自己核对。允许用 AI，但要能讲清每一行在做什么，并在实录里如实披露。
