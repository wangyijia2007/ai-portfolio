# ai-portfolio

这是我的个人作品集仓库，用于记录 16 周人工智能相关课程的学习过程与成果。

## 仓库说明

本仓库包含以下基础文件：

| 文件 | 说明 |
|------|------|
| `README.md` | 个人作品集仓库说明 |
| `hello.py` | 用于验证 VS Code 中 Python 环境可正常运行 |
| `ai任务单.md` | 记录使用 AI 对话工具完成学科任务的过程与结果 |

## 使用方式

在本仓库目录下运行：

```bash
python hello.py
```

若终端输出 `Hello, AI Portfolio!`，说明 Python 环境配置成功。

## 学习计划

本仓库将持续更新 16 周的学习笔记、作业成果与 AI 辅助学习记录。
