## 三问成功输出（use_rag=True）

### 1. 把字句的教学难点有哪些

```
把字句的教学难点包括：忘记说出动作结果或补语、把不适合处置的动词硬套进把字句、与“被”字句、一般主谓宾句混淆。
```

**点评：** 与 W7 语料一致，三个难点可核对，有依据。

### 2. HSK4 词汇量要求是多少

```
HSK4 需要掌握约 1200 个词语。
```

**点评：** 锚定知识库中的旧版 HSK4 数字，避免小模型瞎猜。

### 3. 《愚公移山》可以设计什么课堂活动

```
《愚公移山》可以设计以下课堂活动：

1. 朗读和背诵：组织学生朗读课文，强调“愚公”和“移山”两个关键词，引导学生理解并背诵其中的句子。
2. 品味字词：让学生品味字词，了解“愚公”和“移山”的含义，激发学生对汉字的兴趣。
3. 情景对话：设计情景对话，让学生在角色扮演中练习把字句，感受把字句的表达效果。
4. 诗歌背诵：引导学生背诵《愚公移山》，理解诗歌的内容和情感。
5. 批注和总结：布置学生写批注，总结《愚公移山》中的主要情节和人物，增强学生的阅读体验和理解能力。
```

**点评：** 语料无现成教案，偏生成创造；格式可用，细节需教师改（如活动 3 硬套把字句）。

## 进阶：同一问题 use_rag 开/关对比

**问题：** HSK4 词汇量要求是多少

| 模式 | 原文输出 |
|------|----------|
| `use_rag=False` | HSK4 考试要求词汇量在 6500 左右。 |
| `use_rag=True` | HSK4 词汇量要求需掌握约 1200 个词语。 |

**价值：** 裸答漂到 6500（幻觉），开 RAG 回到语料中的 1200；开关对比一眼可见 RAG 的用途。
