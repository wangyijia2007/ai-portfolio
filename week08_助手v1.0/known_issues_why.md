# 作业 2 ·「已知问题」为什么要诚实写（约 200 字）

README 的「已知问题」不是自我贬低，而是给下一任用户（同学互评、未来的自己、助教）提前画雷区。助手依赖 Ollama、嵌入模型和代理环境，任何一环没装好就会表现为「装完就报错」；如果 README 只写「功能强大、一键运行」，别人照着装失败只会怀疑自己，排障成本翻倍。诚实写出「未 pull 嵌入模型会失败」「机房代理可能劫持 localhost」「0.5b 数字题必须开 RAG」，等于把踩过的坑变成可执行的检查清单。主动写限制是专业：它证明你测过边界、知道适用范围；藏着掖着才是埋雷——Release 看起来完美，复现时全线翻车，互评也无从写起。v1.0 本来就不完美，把限制写清楚，才配得上「可交付」。
