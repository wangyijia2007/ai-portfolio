# W5 本地部署笔记（Ollama）

## 1. 安装步骤

1. 从 `https://ollama.com/download/windows` 下载 `OllamaSetup.exe`（约 1.5GB）。  
   本机直连 GitHub/winget 很慢，最终用 `curl` 从官网 CDN 下完并静默安装。
2. 安装后确认服务：
   ```powershell
   ollama --version
   curl http://localhost:11434/api/tags
   ```
3. 官方 `ollama pull` 拉取模型约 90KB/s，改从 ModelScope 下载  
   `Qwen2.5-0.5B-Instruct` 的 Q4_K_M GGUF，再：
   ```powershell
   ollama create qwen2.5:0.5b -f Modelfile
   ollama list
   ollama run qwen2.5:0.5b
   ```
4. Python 直连示例（机房有代理时加 `trust_env=False`）：
   ```python
   import requests
   s = requests.Session()
   s.trust_env = False
   resp = s.post(
       "http://localhost:11434/api/chat",
       json={
           "model": "qwen2.5:0.5b",
           "messages": [{"role": "user", "content": "用一句话说明什么是把字句"}],
           "stream": False,
       },
       timeout=120,
   )
   print(resp.json()["message"]["content"])
   ```

本机环境：Ollama **0.40.6**；物理内存约 **31.5 GB**。

## 2. 所选模型与理由

| 项目 | 内容 |
|------|------|
| 模型 | `qwen2.5:0.5b`（约 491 MB） |
| 选型原则 | 讲义：先小后大；8GB→0.5b–1.5b，先跑通再升级 |
| 为何不是更大 | 虽有 32GB 内存可跑 4b，但本周目标是“跑通 + 摸脾气”；0.5b 装载快、适合格式固定且可人工校验的任务 |
| 实测 | 首次热调用约 0.3–4.4s；适合课堂演示，质量明显弱于云端大模型 |

术语提醒：**量化**把权重量化降体积；**MCP**是工具协议，两者不是一回事。

## 3. 本地 vs 云端对比（≥5 个学科问题）

同一组问题：本地用 `qwen2.5:0.5b`；云端对照第 4 周 DeepSeek API / 讲义基准（质量参考）。

| # | 学科问题 | 本地速度 | 本地质量观察 | 云端（对照） | 该用哪个 |
|---|----------|----------|--------------|--------------|----------|
| 1 | 用一句话说明什么是把字句 | 0.33s | 说出了“把”，但定义不准（写成“连接动作的短语”） | 通常能准确说处置义/宾语前置 | **云端**（概念要准）；本地只适合快速草稿后人工改 |
| 2 | HSK4 级对词汇量的要求大概是多少 | 2.04s | 胡说成“每单元记 50 汉字”，与《等级标准》四级累计约 3245 不符 | 仍可能幻觉，但更容易贴近标准表述 | **本地不可直接用**；必须对照《等级标准》核验，或云端+核验 |
| 3 | 给《愚公移山》出一道 HSK4 阅读题（题干+四选项） | 1.39s | 格式有了，但内容偏离（修长城等无中生有），类似讲义实测 | 云端选项更贴课文主旨 | **云端出题 + 人工校对**；本地仅练“输出格式” |
| 4 | 解释送气/不送气，各举一声母例子 | 4.37s | 概念散乱，例子不可靠（误把 y 当送气声母） | 能较清楚讲清 p/t/k 与 b/d/g | **云端**（语音知识）；本地不适合当教材依据 |
| 5 | 扩展 45 分钟教案提纲：周末安排 + 因为……所以…… | 3.93s | 有环节骨架，但语法点融入弱、条目空泛 | 更易写出可上课的步骤与检查点 | **本地草拟提纲 → 云端润色**，或下一周双引擎自动分派 |

### 结论（写进笔记）

- **本地 0.5b**：快、免费、数据不出机；适合格式固定、结果可人工校验的批量活（草稿、模板填充）。
- **云端**：质量与知识可靠性更高；适合概念讲解、出题、评语等“要准”的任务。
- **隐私红线**：学生作文、成绩、含姓名学号材料默认本地；上云必须先脱敏。
- **盈亏平衡**：调用少、要质量 → 云端；调用多、要隐私/离线 → 本地。第 6 周用 `llm.py` 按任务自动选边。
