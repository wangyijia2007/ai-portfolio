# 作业 3 · W10 预习：三者辨析 + 希望接上的外部工具

## 各一句话辨析

| 概念 | 一句话 |
|------|--------|
| **Function Calling** | **模型侧机制**：模型只决定「调哪个工具、参数是什么」（常输出 JSON），真正执行仍在我们的程序里。 |
| **MCP** | **工具侧协议**：当工具不在本机、由别人提供时，用统一接口描述「有什么工具、怎么调」，让不同客户端能插拔同一套工具。 |
| **普通 API 调用** | **开发者写死的请求**：代码里直接 `requests.post(...)` 调某个服务，没有「模型现场决定调不调」这一步。 |

关系一句话：Function Calling 管「模型怎么开口点名」；MCP 管「工具怎么对外登记」；普通 API 是二者落地时最常见的传输方式。

## 希望 MCP 帮我接上的 2 个外部工具

1. **在线汉语词典 / 字词释义服务**  
   - 输入：词语  
   - 输出：拼音、词性、例句  
   - 理由：本机 `生词表.csv` 只有十几条，备课查生词需要接到更大的外部词库，但不想把密钥和 URL 散落在多处脚本里。

2. **班级作业 / 测验成绩查询接口**（或 LMS 只读 API）  
   - 输入：学号或任务 ID  
   - 输出：得分、正确率、错题号  
   - 理由：W8 预习里的「算分」工具若能接到真实成绩库，助手才能做课后反馈，而不是只算演示用的假数据。
