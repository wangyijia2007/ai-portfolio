## 第 4 步 · 三者辨析（各 ≤20 字口径）

1. **Function Calling**：模型侧机制，解决「模型点名调哪个工具、带什么参数」。  
2. **MCP**：工具侧协议，解决「工具如何统一登记、被不同客户端发现与调用」。  
3. **普通 API 调用**：开发者写死请求；没有「模型现场决定调不调」这一步。
