## 课后思考（口头抽查备忘）

1. 同一句话问两次答案不完全一样，因为采样有随机性；要更一致，把 `temperature` 调到 `0`。
2. AI 说“HSK4 词汇量 1200”不能直接写进教案，要对照《等级标准》核验（第 7 周伏笔）。
3. 要支持多轮追问，需要把历史对话放进 `messages`（assistant 与 user 交替）。
